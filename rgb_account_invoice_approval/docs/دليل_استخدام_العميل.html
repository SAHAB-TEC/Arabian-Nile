دليل استخدام نظام موافقات الفواتير

شركة النيل العربي — متابعة الفواتير
موجّه للمستخدم النهائي (المالية والإدارات)

الهدف من النظام: ضمان مراجعة كل فاتورة (عملاء أو موردين) من الإدارة المختصة أولاً، ثم عودتها للمالية للمراجعة النهائية والترحيل، مع منع تعديل المبالغ بعد الإرسال.

1) من يستخدم النظام؟

الدورماذا يفعل؟
الماليةإنشاء الفاتورة، اختيار الإدارة، الإرسال، المراجعة النهائية، الترحيل، والاسترجاع عند الحاجة
موظف الإدارةمراجعة فواتير إدارته فقط، ثم الاعتماد أو الرفض

2) مسار الفاتورة

مسودة مالية ← إرسال ← مراجعة الإدارة ← مراجعة نهائية ← ترحيل

مثال: إذا اختُيرت إدارة تقنية المعلومات يصبح المسار:

مسودة مالية → مراجعة تقنية المعلومات → مراجعة نهائية → مرحّل

3) خطوات الاستخدام للمالية

أ) إنشاء الفاتورة وإرسالها

  1. افتح المحاسبة ثم فواتير العملاء أو فواتير الموردين.
  2. أنشئ فاتورة جديدة وأدخل العميل/المورد والبنود والمبالغ.
  3. اختر حقل الإدارة المختصة (إلزامي) مثل: التسويق، العمليات، تقنية المعلومات…
  4. اضغط زر الإرسال، وسيكون نصه حسب الإدارة، مثال: إرسال للموافقة (تقنية المعلومات).
مهم: بعد الإرسال تُقفل الأسعار والكميات والضرائب ولا يمكن تعديلها. يمكن فقط إضافة ملاحظات من خلال صندوق المحادثة (Chatter).

ب) بعد موافقة الإدارة — المراجعة النهائية

  1. ستصل إليك الفاتورة في حالة مراجعة نهائية.
  2. راجع البيانات ثم اضغط اعتماد الفاتورة.
  3. بعد الاعتماد يظهر زر التأكيد/الترحيل — نفّذ الترحيل لإقفال الفاتورة محاسبياً.

ج) الاسترجاع للتعديل

  1. إذا احتجت تعديل المبالغ بعد الإرسال، افتح الفاتورة.
  2. اضغط استرجاع للمالية.
  3. عدّل ما يلزم ثم أعد الإرسال للموافقة.

4) خطوات الاستخدام لموظف الإدارة

  1. سجّل الدخول بحسابك المرتبط بإدارتك.
  2. افتح تطبيق موافقات الفواتير ثم موافقاتي المعلقة.
  3. ستظهر فقط فواتير إدارتك التي بانتظار مراجعتك.
  4. افتح الفاتورة وراجعها (بدون تعديل المبالغ).
  5. اختر أحد الخيارين:
    • اعتماد الفاتورة — لإرسالها للمالية للمراجعة النهائية.
    • رفض — مع كتابة سبب الرفض، فتعود للمالية.
لا يمكنك رؤية فواتير الإدارات الأخرى. مثال: موظف العمليات لا يرى فواتير تقنية المعلومات.

5) معاني الحالات

الحالةالمعنى
مسودة ماليةالفاتورة لدى المالية ولم تُرسل بعد
مراجعة الإدارةبانتظار اعتماد الإدارة المختصة
مراجعة نهائيةبانتظار اعتماد المالية ثم الترحيل
معتمداكتملت الموافقات وجاهزة للترحيل
مرفوضرُفضت؛ يمكن للمالية التعديل وإعادة الإرسال

6) الإدارات المتاحة

  • التسويق
  • المشاريع
  • الإمداد والمبيعات
  • التطوير
  • الخدمات
  • العمليات
  • تقنية المعلومات
  • الأمان والصحة والسلامة

7) ماذا يظهر بعد موافقة الإدارة؟

يظهر اسم الموظف الذي اعتمد الفاتورة من الإدارة في حقل موافق الإدارة، ليبقى التتبع واضحاً للمالية.

8) الإشعارات

عند وصول فاتورة لمرحلتك يصلك عادةً:

  • رسالة بريد إلكتروني
  • نشاط للموافقة داخل النظام
  • إشعار في صندوق الوارد

9) نصائح سريعة

  • تأكد من اختيار الإدارة الصحيحة قبل الإرسال.
  • راجع المبالغ جيداً قبل الإرسال لأنها تُقفل بعده.
  • استخدم الرفض مع سبب واضح لتسهيل التصحيح.
  • استخدم الاسترجاع فقط عند الحاجة الفعلية للتعديل المالي.
