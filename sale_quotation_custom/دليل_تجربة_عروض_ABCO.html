دليل تجربة عروض ABCO — النيل العربي

قبل البدء

  1. تأكد أن الموديول Sale Quotation Custom محدّث (الإصدار 18.0.1.0.6 أو أحدث).
  2. أعد تشغيل السيرفر بعد تحديث بايثون (أو حدّث الصفحة إذا كان يعمل بـ --dev=xml لتعديلات XML فقط).
  3. ادخل بمستخدم لديه صلاحيات: مبيعات + جهات اتصال + مشتريات.

أولاً: الإعدادات المطلوبة (مرة واحدة)

1) إعداد العميل

افتح: جهات الاتصال / العملاء → اختر عميل الشركة (مثل Arabian Gulf Oil Company)

املأ الحقلين:

الحقل مثال الغرض
ABCO Customer Code AG يدخل في رقم ABCO Ref
Customer Ref Label AGOCO يظهر في الطباعة كـ AGOCO Ref.

احفظ العميل.

بدون ABCO Customer Code لن يتم تأكيد أمر البيع (سيظهر خطأ).

2) إعداد أمر البيع / عرض السعر

افتح: المبيعات → عروض الأسعار → إنشاء

أ) البيانات الأساسية

  • اختر نفس العميل المعد أعلاه.
  • أضف منتجاً واحداً على الأقل (كمية + سعر).
  • (اختياري) حدّد بلد المنشأ على السطر — يظهر مجمّعاً في الأعلى.

ب) حقول ABCO في الشاشة

الحقل ماذا تفعل
Customer Offer Ref أدخل رقم العميل يدوياً مثل 147-2024-21-03-XX
Revision مثل 1 أو 2
Offer Validity 30 / 60 / 90
Delivery From / To مثل 12 و 13
Incoterm (Print) مثل FCA USA
Payment (Print) مثل 100% USD CAD
Signatory Name مثل Walid Aldejawi
Signatory Title مثل Supply and Sales Manager | ABCO

ج) تبويب ABCO Cover Letter

الحقل مثال
Cover Addressee Department Manager, Supply Department
Cover Subject Commercial Priced Submission أو اتركه فارغاً ليأخذ الافتراضي حسب التقرير
Cover Body نص الخطاب (موجود افتراضي ويمكن تعديله)

احفظ العرض بدون تأكيد أولاً إن أردت تجربة الطباعة قبل التأكيد.

ثانياً: تجربة الطباعة

أ) الطباعة القديمة (يجب أن تظل تعمل)

من أمر البيع → طباعة / Print → عرض السعر / أمر البيع القياسي

تأكد أنها بنفس شكل الشركة المعتاد.

ب) طباعة ABCO Commercial (مسعّر)

Print → ABCO Commercial Offer

النتيجة المتوقعة 3 صفحات:

  1. صفحة عنوان: Commercial Priced + ABCO Ref + مرجع العميل + Rev
  2. صفحة خطاب: Date / To / Subject / Body / الموقّع
  3. صفحة العرض الأصلية للشركة مع الأسعار

ج) طباعة ABCO Unpriced (بدون أسعار)

Print → ABCO Unpriced Offer

نفس الهيكل (3 صفحات)، لكن في صفحة العرض:

  • الأسعار والمجاميع تظهر -
  • العنوان يكون Technical Unpriced
ملاحظة: إذا لم يتم التأكيد بعد، ABCO Ref قد يظهر فارغاً وهذا متوقع حسب الاتفاق (التوليد عند التأكيد).

ثالثاً: تجربة توليد ABCO Ref

  1. تأكد أن العميل عليه ABCO Customer Code.
  2. من العرض اضغط تأكيد / Confirm.
  3. راقب الحقل ABCO Ref — مثال متوقع: O_AB-AG-260001
    • AG = كود العميل
    • 26 = السنة
    • 0001 = التسلسل السنوي
  4. اطبع Commercial أو Unpriced مرة أخرى وتأكد ظهور الرقم في الصفحات.

رابعاً: تجربة عنوان مرجع العميل الديناميكي

  1. غيّر على العميل Customer Ref Label من AGOCO إلى مثلاً AKAKUS.
  2. افتح العرض / أنشئ عرضاً جديداً لنفس العميل.
  3. في الشاشة والطابعة يجب أن يظهر: AKAKUS Ref. وليس AGOCO Ref.

خامساً: تجربة ترقيم المشتريات

  1. المشتريات → طلبات الشراء / أوامر الشراء → إنشاء
  2. اختر مورد + أضف بنداً.
  3. اضغط تأكيد الطلب.
  4. المتوقع:
    • ظهور ABCO PO Ref مثل PO_AB-260001
    • يصبح اسم أمر الشراء بنفس الرقم

قائمة تحقق سريعة

  • كود العميل + Label محفوظان
  • مرجع العميل اليدوي مُدخل
  • الغلاف (To / Subject / Body / Signatory) مكتمل
  • الطباعة القديمة تعمل
  • Commercial = 3 صفحات + أسعار
  • Unpriced = 3 صفحات بدون أسعار
  • بعد التأكيد يظهر O_AB-...
  • تأكيد المشتريات يعطي PO_AB-...

مشاكل شائعة

المشكلة السبب المحتمل
فشل التأكيد لم يُضبط ABCO Customer Code على العميل
ABCO Ref فارغ في الطباعة العرض لم يُؤكَّد بعد
العنوان ثابت AGOCO لم يُملأ Customer Ref Label على العميل
الطباعة بلا هيدر الشركة تأكد أنك تطبع ABCO Commercial/Unpriced بعد التحديث 18.0.1.0.6 وليس نسخة قديمة من الكاش
